# Extra LOCO Fusion Results

This folder contains the additional leave-one-country-out (LOCO) experiments added to strengthen the Timika severity-scoring paper.

## Purpose

The original paper reported LOCO generalisation on three held-out countries:

- Romania
- Moldova
- Kazakhstan

This extension adds three additional adequately powered held-out countries:

- Georgia
- Ukraine
- Belarus

This increases the held-out evaluation pool from 1,208 CXRs to 4,990 CXRs across six national cohorts.

## Dataset and Manifest

The experiments use the same reconstructed 5,010-image paper cohort.
